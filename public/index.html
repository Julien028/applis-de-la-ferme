Applis de la ferme

Les petits outils de tous les jours, sur le téléphone. Un espace par exploitation, un compte par personne.

Se connecter

Sans compte, les outils marchent aussi : les données restent alors dans l'appareil. Les comptes sont créés par le chef d'exploitation.

Vous avez un mot de passe provisoire : choisissez le vôtre (8 caractères au moins).

Sans case cochée, il consulte et fait les calculs. Modifiable plus tard dans la liste ci-dessus.
